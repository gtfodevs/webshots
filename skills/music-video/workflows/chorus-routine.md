# Chorus routine checklist
- [ ] One routine function, scenes `dance1..danceN`, each starting on a bar inside every chorus
- [ ] Same stage, lights, stamp text and move every time (only the gag line and gag character change)
- [ ] 4-beat move: 1 kick+hop+tilt+camera punch, 2 alt pose+mirror flip, 3 dance pose+flip back+small hop, 4 alt pose+squash
- [ ] Beat-in-bar counter resets on downbeats (`b.downbeat`)
- [ ] Running gag escalation planned for all N choruses; last one is the payoff
- [ ] Story state shows through (damaged/caged characters still dance)
- [ ] Shorts window contains at least one routine
